# 仓库与 Git 工作流

本仓库的默认源码只维护 Qt / C++ / QML。根 README 指向当前文档，AGENTS 约束开发入口，`docs/README.md` 是唯一技术文档索引。不要另建平行 Wiki 或交接首页。

## 日常修改

从 Qt 主线建立 `codex/<主题>` 分支，每个提交只表达一个可说明的变化。已有未提交修改先辨认所有者，不使用 reset、clean、强制覆盖或历史重写来整理工作区。

提交前运行 `python tools/check-repository.py`、`git diff --check` 和相关构建/测试，审查暂存区。源码、字体和许可可以追踪；二进制、profile、数据库、日志、截图证据和本机配置放在忽略目录。

PR 以具体行为和验证结果说明改动；未执行的现场检查要写清楚。合并时优先 squash，让公共主线保留清楚的问题与修复记录。大范围源码切换不强推或删除历史分支来伪装成全新历史。

## 持续集成与交付

CI 构建原生后端与 Qt 应用、运行契约测试和仓库检查。音频硬件、真实账号与上游网络仍需单独现场验证。

手动打包工作流只上传 Actions 构建产物，不自动发布 Release。公开发布、合并或修改默认分支前核对用户授权与具体候选结果。发布包使用 `BottleMusicQt-<版本>-x64.zip` 命名，并保留许可与校验值。

分支清理只删除确认无用且已保留工作成果的分支；已有标签和历史不能随意改写。
