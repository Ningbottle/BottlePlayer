# 当前状态

截至 2026-10-17，Qt 应用仍是开发预览版。源码包含搜索、账户、歌单、历史、统计、设置、均衡器、设备选择、外观和沉浸播放；“有页面/有实现”不等同于所有真实服务场景已验收。

## 已有回归覆盖

- 账户、播放会话、曲库、统计和设置档案契约。
- 推荐列表的过期结果、连续队列推进、取消和失败保留。
- 推荐专辑独立来源、每日歌曲展开收起、侧栏宽度保存和窗口内沉浸歌词。
- PCM 输出格式、设备路由、均衡器及暂停恢复。
- 原生身份提交、请求取消/截止时间、HTTP 预算及数据库生命周期。

2026-10-17 的本地现场验证覆盖了连接耳机的实际输出、在线歌曲及连续推荐前两首。该结果只代表当时环境，不能推断所有设备、歌曲或上游接口稳定。

## 每次候选交付仍需验收

- 无声、设备重连、音质切换失败后的恢复，以及不同驱动/多输出设备。
- 真实账户的扫码、换号、权限变化、歌单写入和网络失败；写操作只在用户授权的账号执行。
- 上游返回变化、不可播放内容、更新渠道和完整便携包启动。
- 长时间播放、缩放、多屏/DPI、外观切换和性能表现。

不按主观百分比判定迁移完成。候选构建应记录提交、运行库、测试结果和实际未验证范围；具体命令见 [构建与验证](build-and-test.md)。
