# BottleMusic 产品愿景

## 产品定位

BottleMusic 是一个 Windows 原生音乐客户端，目标是在保持现代音乐软件体验的同时，显著降低 Electron 形态带来的内存和启动成本。

它不是旧前端的逐像素搬运，也不是简单把 Node API 翻译成 C++。它是一次以低内存、原生渲染、清晰模块边界为核心的重设计。

## 目标

- 使用纯 Win32 + Direct2D + DirectWrite 实现主界面。
- 使用 C++20 实现后端核心、播放核心、图片缓存和本地存储。
- 使用 Media Foundation 作为首选播放管线。
- 播放中整进程内存控制在 180MB 以内。
- 首版 UI 参考用户提供的 Melody 风格截图。
- 兼容旧 Electron 前端只作为迁移期验证手段。

## 非目标

- 首版不追求跨平台。
- 首版不嵌入 Chromium、WebView2、Electron 或 Node。
- 首版不默认引入 FFmpeg、libmpv 或大型 UI 框架。
- 首版不完整复刻所有旧 Vue 组件和所有旧页面。
- 首版不为了填页面而伪造酷狗接口数据。

## 首版体验范围

首版应让用户能完成一条完整音乐路径：

1. 打开 BottleMusic。
2. 看到 Melody 风格首页。
3. 搜索歌曲。
4. 查看搜索结果。
5. 播放歌曲。
6. 查看歌词和播放队列。
7. 调整音量、进度和播放状态。

## 视觉方向

视觉以浅色、温和、图像驱动、低噪声为主。界面应轻盈但不是空洞，列表应密集但不拥挤。蓝色作为播放、选中、进度和当前歌词的强调色。

## 性能方向

性能目标不是单纯“C++ 更快”，而是通过模块归口和预算控制实现：

- 图片缓存有上限。
- 列表绘制虚拟化。
- UI 线程不等待网络和数据库。
- 大 JSON 不长期驻留内存。
- 播放管线不整曲解码缓存。
- 每个阶段都能输出内存快照。
