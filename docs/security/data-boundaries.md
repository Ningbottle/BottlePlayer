# 数据与安全边界

账号、数据库、播放历史、设备标识和用户档案属于用户。源码整理、测试和构建不授权读取、上传、删除或覆盖日常数据。

- 测试使用独立 profile、合成夹具和明确选择的输入文件。
- 会话使用 Windows 当前用户范围 DPAPI；导入只接受设置和统计白名单，不复制会话。
- 账户变化通过身份版本和条件提交隔离，过期请求不能写入新账户。
- JSONL 诊断只写允许的字段，不写签名地址、会话或完整响应。分享前仍需检查曲目、设备、个人路径与时间信息。
- 文件导入读取源档案并备份目标；更新下载要求 HTTPS、预期仓库、Qt 包名和 SHA-256，执行或打开由用户触发。
- API Key、真实二维码、数据库、日志、导出档案和签名请求证据不进入公共 Git 历史。

网络服务、隐私与报告方式见 [隐私说明](../../PRIVACY.md) 和 [安全政策](../../SECURITY.md)。素材和字体保留 [许可归属](../../desktop/qt/licenses/THIRD_PARTY.md)，仓库整理不消除第三方分发义务。
