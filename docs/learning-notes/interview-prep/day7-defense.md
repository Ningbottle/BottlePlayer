# 第七天：项目答辩与模拟追问

## 今日目标

把前 6 天的内容合成一次完整面试：自我介绍、项目讲解、八股追问、手写代码、反问面试官。

## 上午：自我介绍与项目开场

1. 请做一个 1 分钟自我介绍。
2. 你为什么选择 C++ 方向？
3. 你最近最主要的项目是什么？
4. 你在 AI-SDK 项目里负责什么？
5. 你为什么做这个项目？
6. 这个项目的用户是谁？
7. 项目目前完成到什么程度？
8. 项目有哪些核心模块？
9. 项目里你最满意的设计是什么？
10. 项目里你最想优化的地方是什么？
11. 这个项目和课程 demo 有什么区别？
12. 这个项目用了哪些第三方库？
13. 为什么选择 cpp-httplib？
14. 为什么选择 SQLite？
15. 为什么选择 jsoncpp？
16. 为什么选择 spdlog？
17. 你的项目怎么构建和运行？
18. 项目运行时需要哪些配置？
19. 如果没有 API key，项目怎么表现？
20. 如果让别人使用你的 SDK，他需要看哪些接口？

> [!tip]- 开场要求
> - 不要一上来讲实现细节。
> - 先讲“问题 -> 方案 -> 架构 -> 亮点”。
> - 每句话都要能引导到你熟悉的追问点。
