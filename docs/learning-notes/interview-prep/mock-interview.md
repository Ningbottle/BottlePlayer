# 终极面经：模拟面试与追问清单

> 用法：这不是答案稿，是面试流程剧本。每一轮只看题目和追问方向，自己口述答案。

## 一面：C++基础 + 项目初筛

### 开场

1. 简单介绍一下你自己。
2. 你为什么投 C++ 开发？
3. 你最近做的 AI-SDK 项目是什么？
4. 这个项目你花了多久？
5. 你在项目里主要负责哪些模块？

### C++ 基础

1. 指针和引用区别。
2. const 指针和指向 const 的指针区别。
3. static 在不同位置的含义。
4. new/delete 和 malloc/free 区别。
5. 堆和栈区别。
6. 深拷贝和浅拷贝区别。
7. 析构函数为什么要虚函数。
8. 构造函数为什么不能是虚函数。
9. C++ 多态底层机制。
10. 虚表和虚指针大概在哪里。
11. 左值和右值区别。
12. `std::move` 做了什么。
13. `unique_ptr` 和 `shared_ptr` 区别。
14. 循环引用怎么解决。
15. lambda 捕获方式区别。

### STL

1. vector 底层结构。
2. vector 扩容过程。
3. vector 迭代器失效场景。
4. map 和 unordered_map 区别。
5. unordered_map rehash 的影响。
6. list 和 vector 怎么选。
7. push_back 和 emplace_back 区别。
8. reserve 和 resize 区别。
9. string 的常见坑。
10. 容器里放智能指针有什么注意点。

### 手写代码

1. 反转链表。
2. 判断链表是否有环。
3. 合并两个有序链表。
4. 二叉树层序遍历。
5. 快速排序。
6. TopK。
7. LRU 缓存。
8. 单例模式。
9. shared_ptr 极简版。
10. 生产者消费者。

> [!tip]- 一面目标
> - 基础题别追求华丽，先稳。
> - 每道题尽量说出一个“项目中哪里遇到过”。
> - 手写题先讲边界条件，再写代码。

### 项目网络追问

1. 你的项目里哪里用到了 SSE？
2. DeepSeek / GLM 和 Ollama 的流式协议有什么不同？
3. 你怎么处理 TCP 半包？

5. 服务端为什么把 chunk 包成 JSON？
6. 前端 markdown 渲染为什么要等 done？
7. 如果用户中途关闭页面怎么办？
8. 如果上游模型卡住怎么办？
9. 如果上游返回非法 JSON 怎么办？
10. 如果一次返回多个 event 怎么办？

> [!tip]- 二面目标
> - Linux 和网络题必须说“系统调用/协议边界/错误场景”。
> - 不要把 SSE 当成玄学，核心就是长连接 + 事件分隔。
> - 面试官问 epoll 时，不会就诚实说项目用了 cpp-httplib，但能讲如果手写会怎么做。
