# C 语言基础

C 语言是 [[C++ 对象模型]] 的前置基础，也是整个 [[C++ 学习路径]] 的起点。

## 核心模块

### 函数
C 语言函数是过程式编程的基本单元。涉及参数传递（值传递 vs 指针传递）、栈帧结构、递归调用等。详见 [[递归与算法]]。

### 操作符
算术、位、关系、逻辑操作符，以及隐式类型转换规则。

### 指针
指针是 C 语言的灵魂，也是贯穿整个学习路径的核心概念：
- 指针基础：地址、解引用、指针运算
- 指针与数组的关系
- 函数指针与回调
- 多级指针

指针的深入理解是学习 [[C++ 对象模型]]（this 指针、虚表指针）和 [[数据结构与算法]]（链表、树的节点链接）的前提。

### 内存管理
- 栈 vs 堆
- malloc/free
- 内存对齐（进阶话题，见 [[内存对齐与底层优化]]）

### 字符函数与内存函数
- strlen, strcpy, strcmp, strcat, strstr
- memcpy, memmove, memset, memcmp

## 与其他概念的关系

- C 基础 → [[C 语言进阶]] → [[C++ 对象模型]]
- 指针 → [[数据结构与算法]]（链表、树、图的实现）
- 内存管理 → [[RAII 与智能指针]]
- 函数指针 → [[回调与事件驱动]]（muduo 的核心模式）
