# C++ 学习路径

> 源自用户笔记 `1.c++学习/00-学习入口.md`，这是整个 C++ 学习的 MOC（Map of Content）。

## 六层递进结构

### 第一层：C 语言基础
函数、操作符、指针、内存管理、字符/内存函数。→ 详见 [[C 语言基础]]

### 第二层：C 语言进阶
递归、高级指针（多级指针、函数指针数组）、内存对齐。→ 详见 [[内存对齐与底层优化]]

### 第三层：C++ 对象模型
类和对象、构造/析构、继承、string 类。→ 详见 [[C++ 对象模型]]

### 第四层：数据结构与 STL
顺序表、栈、队列、堆、二叉树、排序算法、vector、list、模板。→ 详见 [[数据结构与算法]] 和 [[STL 容器与模板]]

### 第五层：实践与延伸
项目实战（酷狗音乐）、面试冲刺。

### 第六层：资料整理
C++ 八股文、面试资料汇编。

## 推荐复习路径

1. 对象模型 → 引用 → 拷贝控制 → 继承多态
2. 容器 → 模板 → 迭代器 → 复杂度
3. 用面试资料串联所有知识点
4. 连接到 Linux、项目和面试冲刺
