#  一.static 修饰全局变量：

局部变量的作用域一般有限，和生命周期差不多；

static可以改变该局部变量的生命周期，不改变其作用域；

其本质是改变了他的存储方式；

#  二.static 修饰全局变量：

全局变量是具有外部属性链接的，一般与extern连用；

可以随时改变的；

但是被static 修饰后没有外接链接属性，不允许跨属性跨文件交流，只能在自己.c的文件使用；

# 三 .static修饰函数：

函数原本就具有外部属性链接；

但是被static 修饰后没有外接链接属性，不允许跨属性跨文件交流，只能在自己.c的文件使用；
