## 1.2 游戏棋盘的布置
### 1.2.0棋盘的初步考虑：
一开始考虑到一个棋盘，如果0是空白，1是雷。但是周围八个有一个雷则会显示1，会歧义；

如果考虑到# 为空白，*为雷，数字统计雷的个数，则会乱；

则考虑到两个棋盘，一个棋盘为show（对外展示，里面空白为*），另一个棋盘为mine（对内部使用，0为空白，1为炸弹）；

### 1.2.1.布置的细节：

先定义一个ROW行为9，COL列为9 ，为一个9*9的棋盘；

随后定义ROWS为ROW+2，COLS为COL+2；

定义函数即initboard 来重新放置*和0；

在game函数中有init，display，set,find函数的具体的实现；
