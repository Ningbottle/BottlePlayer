# Obsidian笔记管理

## 📋 基本信息
- **技能名称**: obsidian
- **类别**: 笔记管理 (note-taking)
- **用途**: 读取、搜索、创建、编辑Obsidian笔记

## 🎯 主要功能

### 1. 笔记操作
- **创建笔记**: 创建新的Markdown笔记
- **读取笔记**: 获取笔记内容
- **编辑笔记**: 修改现有笔记
- **删除笔记**: 删除不需要的笔记

### 2. 搜索功能
- **全文搜索**: 搜索笔记内容
- **标签搜索**: 按标签筛选
- **链接搜索**: 查找双向链接
- **高级搜索**: 组合条件查询

### 3. 知识管理
- **双向链接**: `[[]]`语法链接笔记
- **标签系统**: `#标签`分类管理
- **图谱视图**: 可视化知识网络
- **模板系统**: 预设笔记模板

## 💡 使用场景

### 学习笔记

## 🔗 双向链接技巧

### 创建链接
```markdown
# 在笔记中链接其他笔记
- [[笔记标题]]
- [[笔记标题|显示文本]]
- [[笔记标题#锚点]]
```

### 使用别名
```markdown
# 使用别名简化链接
- [[机器学习基础|ML基础]]
- [[Python编程语言|Python]]
```

### 嵌入笔记
```markdown
# 嵌入其他笔记内容
![[笔记标题]]
![[笔记标题#段落]]
```

## 🏷️ 标签系统

### 标签分类
```markdown

# 子标签

```
