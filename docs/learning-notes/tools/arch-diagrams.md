# 架构图设计

## 📋 基本信息
- **技能名称**: architecture-diagram
- **类别**: 设计创作 (creative)
- **用途**: 深色主题SVG架构图、云图、信息图

## 🎯 主要功能

### 1. 架构图类型
- 微服务架构图
- 云基础设施图
- 系统流程图
- 网络拓扑图
- 数据流向图

### 2. 设计风格
- 深色主题（专业感）
- 现代扁平化设计
- 清晰的图标和连线
- 响应式布局

### 3. 输出格式
- SVG矢量图（可缩放）
- HTML嵌入式
- 可直接用于文档

## 💡 使用场景

### 系统架构设计
```
"画一个电商系统的微服务架构图，包含用户服务、订单服务、支付服务"
```

### 云基础设施
```
"设计一个AWS云架构，包含EC2、RDS、S3、Lambda"
```

### 技术文档
```
"为这个API网关画一个架构图，用于技术文档"
```

## 🔧 设计要素

### 基本组件
- **服务节点**: 矩形框，带图标
- **数据库**: 圆柱体图标
- **消息队列**: 队列图标
- **负载均衡**: 负载均衡器图标
- **外部服务**: 云图标

### 连接线
- **实线箭头**: 同步调用
- **虚线箭头**: 异步消息
- **双向箭头**: 双向通信
- **不同颜色**: 区分不同类型的连接

### 布局原则
- **分层架构**: 从上到下，从外到内
- **模块化**: 相关组件放在一起
- **清晰性**: 避免交叉连线
- **一致性**: 统一的图标和样式

## 🎨 设计规范

### 颜色方案
- **背景**: 深灰色 (#1a1a1a)
- **节点**: 深蓝色 (#2d3748)
- **文字**: 白色 (#ffffff)
- **强调色**: 蓝色 (#4299e1)
- **警告色**: 红色 (#e53e3e)

### 字体
- **标题**: 无衬线字体 (Arial, Helvetica)
- **正文**: 等宽字体 (Consolas, Monaco)
- **大小**: 根据层级调整

### 图标库
- 使用通用技术图标
- 保持风格一致
- 避免过于复杂

## ⚠️ 设计原则

1. **简洁性**: 避免过度装饰，突出核心架构
2. **可读性**: 文字清晰，图标易识别
3. **一致性**: 统一的风格和配色
4. **可扩展性**: 预留扩展空间
