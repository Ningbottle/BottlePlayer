## 推荐学习顺序

1. 先装好 Git，配置好用户名和邮箱
2. 理解工作区 → 暂存区 → 仓库 的三层模型（这是核心）
3. 反复练习 add → commit → log 的基本循环
4. 学会创建分支、切换分支、合并分支
5. 学会用远程仓库（GitHub/Gitee）协作
6. 最后了解回退、标签和协作规范
