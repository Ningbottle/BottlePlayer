# C++ 八股资料阅读入口

这页是给你复习和继续整理 C++ 面试资料用的入口页。
它的作用不是重复原 PDF，而是把 `外部资料 -> 逐页转写 -> 你已有笔记 -> 面试复述` 这几层接起来。

## 这次我帮你整理出来的两份核心材料

- 清洗排版版：[[1.c++学习/34.【资料整理】亮白风格C++八股文-清洗排版版]]
- 逐页转写版：[[1.c++学习/32.【资料整理】亮白风格C++八股文-逐页转写版]]
- C++ 主入口：[[1.c++学习/00-学习入口]]

## 关于这份 PDF 转写，你先知道 3 件事

1. 这份 Markdown 主要来自原 PDF 的文字层提取，所以大部分正文已经能搜索、能双链、能继续整理。
2. 有少量页面是图片页、思维导图页或文字层缺失页，所以会看到“无法稳定提取正文”的提示。
3. 原 PDF 的字体编码比较特殊，所以我另外做了一份“清洗排版版”，优先推荐你看那一份。

## 你最适合怎么用这份资料

### 用法 1：当作检索版资料库

- 遇到面试题时，先在 [[1.c++学习/34.【资料整理】亮白风格C++八股文-清洗排版版]] 里搜关键词。
- 搜到对应页面后，再回链到你自己的原理笔记。
- 最后把你自己的理解写回仓库，而不是只停在外部资料。

### 用法 2：当作补缺口的参照物

- 先从你已有笔记出发。
- 遇到“我这块没写全”时，再去 PDF 清洗版或转写版补充。
- 不要反过来把整本 PDF 当作新的唯一主线。

### 用法 3：当作面试复述训练材料

- 先读一页或一个主题。
- 再用自己的话复述“概念是什么、为什么这么设计、优缺点是什么、面试怎么答”。
- 最后把结果写进 [[6.4月C++岗位面试冲刺/00-学习入口]] 对应的复盘笔记。

## 推荐复习顺序

1. 先读 [[1.c++学习/00-学习入口]]，确定你现在处于哪一层。
2. 再去 [[1.c++学习/34.【资料整理】亮白风格C++八股文-清洗排版版]] 搜对应主题。
3. 再回到你自己的原笔记，补“核心结论 / 易错点 / 一句话复述”。
4. 最后把这块压缩成面试表达，写去 [[6.4月C++岗位面试冲刺/00-学习入口]]。
